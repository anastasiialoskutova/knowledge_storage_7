### Повторне використання зовнішньої онтології

Для розробки моделі предметної області використовується зовнішній словник **Schema.org** (https://schema.org/).

Schema.org застосовується для стандартизованого опису товарів, організацій, пропозицій, замовлень та взаємодій користувачів у вебсередовищі.

У межах роботи використовуються такі зіставлення:

- `Product` — `schema:Product`, описує товар.
- `Brand` — `schema:Brand`, описує торгову марку.
- `Offer` — `schema:Offer`, описує комерційну пропозицію.
- `Order` — `schema:Order`, описує замовлення.
- `ProductReview` — `schema:Review`, описує відгук клієнта.
- `ProductRating` — `schema:Rating`, описує оцінку товару.
- `ProductView` — `schema:ViewAction`, описує перегляд товару.

Використання Schema.org дає змогу повторно використовувати загальноприйняті поняття та полегшує інтеграцію моделі з іншими вебсистемами. Водночас класи `Recommendation`, `RecommendationModel`, `CustomerProfile` та `RelevanceScore` визначаються у власній моделі, оскільки вони описують специфіку персоналізованих рекомендацій.

Зіставлення в цій лабораторній є концептуальним: для повної OWL/RDF-онтології відповідності потрібно формально визначити URI класів і властивостей та тип зв'язку між ними.# knowledge_storage_7
